# Посібник користувача: KROK Assistant v10.0 Swarm Engine 📖

## 1. Робота з лініями (Agent Lines)
1. **Line 1 (Веб-розробка):** виберіть готовий шаблон або введіть текстовий запит для генерації сайту. Скористайтеся інтерактивним пісочником. Перед публікацією відкрийте **L5 Security Gate** для перевірки безпеки.
2. **Line 2 (Промпт інженерія):** використовуйте Генеральний системний промпт або оберіть поведінковий архетип (SEO, QA, Юрист, Фольклор). Натисніть "Тестувати промпт", щоб перевірити взаємодію.
3. **Line 3 (Скрейпінг):** введіть URL сторінки для очищення від рекламних банерів та отримання структурованого JSON/CSV.
4. **Line 4 (Фактчекінг):** перевірте сумнівні твердження. Твердження з надійністю < 25% автоматично відсікаються, а автентичний фольклор зберігається з бейджем культурної спадщини.
5. **Line 5 (Продуктивність):** перетворюйте цілі у покрокові плани SMART з залежностями та критеріями готовності.
6. **Line 6 (Автоматизація):** завантажуйте готові схеми для n8n та Make кнопкою "Завантажити конфігурацію".
7. **Line 7 (Рецепти):** безпечні калькуляції еко-засобів з правилом несумісності кислот та хлору.

## 2. Публікація KROK 10 на GitHub
1. Перейдіть до **Line 1 → GitHub Publisher** або відкрийте модальне вікно публікації.
2. Авторизуйтесь через **GitHub OAuth** або введіть **Personal Access Token (PAT)** з правами `repo`.
3. Оберіть режим:
   - **Опублікувати згенерований сайт (Single Web App)**
   - **⚡ Опублікувати САМ КРОК 10 на GitHub (Повний репозиторій)**
4. Натисніть кнопку публікації. Система автоматично створить репозиторій, закомітить файли ядра та налаштує проєкт!

## 3. Справжнє голосове введення
- Натисніть кнопку з мікрофоном у правому нижньому кутку.
- Оберіть мову розпізнавання: **Українська (uk-UA)** або **English (en-US)**.
- Говоріть у мікрофон — текст розпізнається на льоту через браузерний рушій Web Speech API без підстановки статичних скриптів.
- За потреби відредагуйте текст вручну та натисніть "Передати до рою агентів".
